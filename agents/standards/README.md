# 标准库索引

## 适用与优先级

- 先按 `lifecycle-gates.md`「任务适用规则」判断流程，再读相关标准章节；咨询、定位与低风险小改动不强制完整生产流程。
- SERVICE_TIER 表示服务影响，变更风险决定本次验证范围；二者分别判断，不降低等级来绕过验收。
- 项目专属规则按 AGENTS.md 优先级执行；差异明确记录，不把全局默认值冒充已确认业务承诺。安全、授权和真实取证底线仍须遵循。
- 存量差距只记录本次相关风险与收敛路径，不顺手重写无关代码。

## 规则与指标归属

每类规则只有一个维护源。其他文档链接其定义，项目文档记录实际选用值、依据与实测结果。

| 文档 | 唯一维护内容 | 读取时机 |
|---|---|---|
| `nfr-baseline.md` | SERVICE_TIER、SLO/SLI/SLA、RTO/RPO、延迟/容量目标、通用调用超时起点、安全及数据生命周期 | 新系统定级、相关目标或能力变化 |
| `system-design.md` | 架构边界、契约与版本、扩展判断、数据演进、设计参数与扩容触发参考 | 模块、接口、数据或架构变化 |
| `resilience-and-ops.md` | 重试/熔断/限流参数、稳定性/演练周期、部署、恢复、发布与应急流程 | 相关运行风险、生产发布、故障复盘 |
| `lifecycle-gates.md` | 流程适用、阶段验收、测试层次/覆盖率、严重程度、状态/合并/豁免及报告协议 | 流程选择、测试审查收口、提交或上线门禁 |
| `anti-patterns.md` | 风险模式、检测方法与修复方向 | 相关方案、代码或上线风险核对 |

角色文件只规定职责、步骤、证据与停止条件，不复制标准清单；技能操作细节由对应 SKILL.md 维护。agents 的分发维护见 ai-config-sharing。

## 约束词表

| 词 | 含义 |
|---|---|
| 必须 | 在声明的适用范围内满足；未满足按 lifecycle-gates 判失败、待验证或有效豁免 |
| 应该 | 推荐；未采用时说明相关影响与替代措施，不自动判失败或警告 |
| 可以 | 可选，无强制后果 |

强制程度须结合适用范围和实际证据，不因全文出现“必须”就扩大任务。非适用项说明理由；适用项的豁免、不可豁免项与状态规则统一见 lifecycle-gates「门禁状态与报告」。
