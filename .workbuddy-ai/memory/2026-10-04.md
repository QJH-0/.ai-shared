### 关键实测（L4 视频管道）

- 托管 venv `C:\Users\20448\.workbuddy-ai\binaries\python\envs\default` 装入 manim 0.21.0 +
  imageio-ffmpeg 0.6.0（内置 ffmpeg v7.1，**无 ffprobe**）+ edge-tts，venv 由 192 MB 增至 441 MB。
- 管道四步全部跑通并产出可播放 MP4（H.264 854×480 + AAC，11.04 s，176 KB）：
  manim 渲染 → edge-tts 配音 → `tpad` 补齐 → ffmpeg 合成。
- **踩坑 1**：只加 `-shortest` 会截掉尾部旁白（视频 2.40 s + 旁白 5.59 s → 输出 4.40 s，丢 1.19 s）。
  必须先 `tpad=stop_mode=clone:stop_duration=<音频-视频>` 补足，输出才与旁白等长。
- **踩坑 2**：manim 画质参数必须合并写（`-qm`）；`-m` 报 `No such option '-m'`。
- **踩坑 3**：manim 默认从 PATH 找 ffmpeg，本机 PATH 没有；用 `--config_file` 指定 `manim.cfg`
  的 `ffmpeg_executable` 解决。
- **踩坑 4**：无 LaTeX，`MathTex` / `Tex` 不可用，只能用 `Text`（Pango）+ Unicode 数学符号。
- **踩坑 5**：给 Windows 版 Python 传路径必须写 `C:/...`；Git Bash 的 `/c/...` 会变成
  `C:\c\Users\...` 并报文件不存在。
