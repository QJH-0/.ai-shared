# 十步提示词模板

每一步都是一段可直接粘贴到对话式 AI（Claude、Codex、ChatGPT 等）的提示词。把 `【主题】` 替换成实际要学的内容即可。

模板的用途有两个：一是外部工具里复用，二是让当前 agent 明确每一步的**输出形状**——照着模板的结构产出，不要自由发挥。

---

## 第 1 步 · 五视角 STORM

```
我要快速了解【主题】。请你同时扮演以下五位不同领域的专家，从各自视角出发拆解这个主题。
每位专家独立输出一份分析，不要互相引用，结论不要重复。

1. 实践者：以一线使用者或操作者的视角，说明这个主题"是什么"、"怎么用"，
   给出真实场景中的具体做法和踩过的坑。
2. 学者：从理论高度做系统性学术剖析，说明背后的原理、主要流派与未解问题。
3. 怀疑者：从安全、风险和技术批判角度提出质疑，指出它可能在哪里失效、被夸大或被误用。
4. 经济学家：从成本、商业可行性、规模化和长尾风险角度分析，算清楚这笔账划不划算。
5. 历史学家：从技术史、制度史与文化演变视角判断发展节奏，指出历史上相似的事发生过什么。

最后给出一段五句话的交叉总结，点出五方观点的分歧点。
```

## 第 2 步 · 矛盾突破

```
把上面五位专家的分析放在一起，让它们"互相吵架"。输出两份清单：

A. 共识清单：五位都认可的观点（逐条列出，标注是哪几位提出的）
B. 盲区清单：五位都没有提及的问题、被默认接受但未经检验的假设、
   以及所有人都绕开的地方

然后指出：五方争议最激烈的那一点是什么？为什么它最值得深挖？
```

## 第 3 步 · 综合简报

```
把五视角分析和矛盾图谱压缩成一份决策级简报，只输出四部分：

1. 按重要性降序排列的五个关键发现
2. 一个隐藏关联（表面上不相关、实际互相牵制的两件事）
3. 一条具体行动建议（要能直接执行，不要"多了解"这种废话）
4. 一个前沿问题（这个领域真正悬而未决的那一个）

要求：整份简报能在一屏内读完，语言直白，不堆术语。
```

## 第 4 步 · 同行评审自检

```
现在请你扮演一位斯坦福教授，对上面这份简报做同行评审。逐条检查：

- 对每条关键发现给出可靠性评分（1~10）并说明评分理由
- 指出哪些结论证据不足、哪些是推测被写成了事实
- 提出具体纠偏建议
- 检查是否存在来源偏差（只引用了某一方立场）和事实错配

最后给出一个总体判断：这份简报可以拿去决策了吗？如果不行，缺什么。
```

## 第 5 步 · 资源筛选

```
请你担任这个领域的策展人。从市面上能找到的学习资源（视频、课程、书籍、
社区、官方文档）中，筛选出五个最值得投入时间的输入材料。

要求：
- 每个资源说明"为什么选它"和"它解决哪个具体问题"
- 明确指出哪些看起来热门但实际低价值的资源应该避开
- 最后给出一条一周内可以走完的学习路径，按天拆解
```

## 第 6 步 · 学习阶梯

```
把【主题】拆解成五个清晰的难度级别，输出一张五级能力地图。

每一级都要写清楚：
- 这一级叫什么
- 达到什么状态算过关（用可观察的行为描述，不要用"熟悉""了解"这种模糊词）
- 这一级的人能做什么、还做不了什么

最后告诉我：一个完全的新手从第 1 级走到第 3 级，大概需要投入多少时间。
```

## 第 7 步 · 核心拆解与十次课计划

```
提炼【主题】最核心的 20% 概念与技能——就是掌握之后能覆盖 80% 实际场景的那部分。
把它们排成一个十次课的学习计划。

每次课包含：学习目标 / 核心概念 / 练习内容 / 参考资源 / 复习题。

十次课之后，附一个可验收的实战小项目：这个项目做完，就能证明"真的会用"，
而不是"看过"。请写清项目的验收标准。
```

## 第 8 步 · 考到崩溃

```
现在来考我。围绕【主题】出题，分四个难度档位：
- 初级：基本概念辨析
- 中级：场景判断与选择
- 高级：方案设计与权衡
- 专家级：边界情况、反直觉结论、开放争议

先只出初级档，等我答完再给下一档。不要提前给答案。
每题答完后，指出我错在哪里、暴露出什么知识漏洞。
```

## 第 9 步 · 费曼循环

```
针对我上面答错的部分，请把相关概念讲给一个 12 岁的学生听。
只能用简单词汇和生活化的例子，不能出现专业术语——如果非要用，
必须先解释清楚。

讲完后，反问我三个问题，检验我是不是真的懂了。
```

## 第 10 步 · 一页速查表

```
把前面所有内容压缩成一张一页速查表，供我在面试前、开会前、
向别人讲解前快速回顾。

要求：
- 一页装得下（大约 40~60 行）
- 按"是什么 / 关键数字 / 核心争议 / 常见坑 / 一句话总结"组织
- 每条都要能被单独检索调用，不要写成连贯长文
- 删掉所有过程性内容，只留结论和判断依据
```
