# AI 输出可读性：四级表达升级

## 判据

先问一句：**读者能不能一眼看懂？**

- 能 → 直接写，不升级。
- 不能 → 换一种载体，而不是把话说得更长。

四级是**顺序候选**，不是必须逐级走。多数问题停在 Level 1 或 Level 2 就解决了。

| 级 | 形态 | 典型场景 | 产出 |
|----|------|----------|------|
| 1 | 规范文本 | 结论、说明、汇报 | 无独立产物 |
| 2 | 图表 | 流程、方案对比、模块关系 | Markdown 内嵌图 / SVG |
| 3 | 交互网页 | 复杂概念、可动手探索 | 单文件 `.html` |
| 4 | 讲解视频 | 底层原理、公式推导 | `.mp4` |

## Level 1：规范文本

**适用**：任何以文字交付的解释、说明、汇报。

**底线摘要见 `AGENTS.md` §2.1**（一词一义 / 一句一事 / 控制句长 / 主动语态 / 重点前置）。本节只写它没覆盖的操作细节。

### 解释类内容：先定结构，再选载体

内容是「讲清某个机制 / 链路为什么这样运转」时，**内容契约**（骨架先行、八项输出结构、失效矩阵、自检题）见 `skills/mechanism-explainer`；本 skill 只决定用哪一级载体承载它，不重复定义内容规则。

### 先分类，再套规则

ASD-STE100 对两类文本的规则不同，先判定属于哪类：

| 类型 | 用途 | 句式 | 句长上限 |
|------|------|------|----------|
| 程序性 | 告诉读者做什么 | 祈使句 | 20 词 |
| 描述性 | 解释是什么、怎么运作 | 简单现在/过去/将来时 | 25 词 |

一段内不要混用。步骤里的说明性注释按描述性处理。

### 补充规则（超出底线摘要的部分）

- **一句话一条指令**。复合指令拆开，只有紧密相关的动作才能同句。
- **段落不超过 6 句，只讲一个主题**。
- **名词簇不超过 3 个词**，更长的用介词断开（`冷却系统的风扇`，不是 `冷却系统风扇组件外壳`）。
- **不用缩写式**（`don't` → `do not`），保留冠词（a / an / the），不为了短而省略成分。
- **不用分号**，拆成两句。
- **动词用简单时态**，不用助动词堆叠（`可能会有所帮助地改善` → `改善`）；`-ing` 形式只作技术名词或修饰语。
- **术语一次选定**：同一概念全篇一个词（选了 `配置` 就不再换 `设置`）。

### 提示词模板

```
用 ASD-STE100 约 80% 强度重写下面这段：保留全部技术信息与数字，
拆开长句，一句一事，主动语态，术语全文统一。不要为了变短而删信息。
```

「约 80%」的作用是**兼顾清晰度与可读性**，不追求逐条合规——逐条合规的 STE 文本读起来很生硬。

### 中文适配

ASD-STE100 是英文规范，20/25 词上限对中文无对应标准。中文按**一句一事 + 主动语态 + 术语统一**执行，句长以「读一遍不用回头」为准。

**不要把 STE 用在**营销文案、有语气要求的文本上——STE 会刻意抹掉语气，这是它的设计目标，不是缺陷。

### 元技巧：把规则固化下来

可以让 AI 复盘过往对话，总结反复出现的表达问题。但**必须逐条经用户确认后才能写入 `AGENTS.md`**（`AGENTS.md` §2 禁止 AI 自行增加规范）。

```
复盘我们最近的对话，列出我在理解你输出时反复遇到的表达问题，
每条给出规则草案。先只列出来，等我确认后再写入 AGENTS.md。
```

## Level 3：交互网页

**适用**：概念需要动手探索（调参数看变化、折叠展开、分步走查），静态图讲不透。

**产出**：**单文件 `.html`**，内联全部 CSS / JS，无外部依赖，浏览器双击即可打开。

**注意区分**：`C:\Users\20448\.ai-shared\skills\canvas` 是 Cursor 专用的 `.canvas.tsx` 实时画布（依赖 `cursor/canvas` 运行时，需与对话并排），**不是**单文件 HTML。需要可独立分发的单文件时，不要用 canvas。

**提示词模板**：

```
把这篇论文整理成一个单文件 HTML 页面：内联全部样式与脚本，
核心原理做成可交互卡片，参数用滑块驱动，浏览器直接打开即可用。
```

## 选择决策

1. 一句话能说清 → Level 1，结束。
2. 是「关系 / 顺序 / 对比」类信息 → Level 2。
3. 需要读者动手试才能懂 → Level 3。
4. 需要「动起来」才能懂（推导、演化、变换）→ Level 4。

**升级的收益必须大于读者的打开成本**。为一句结论做一个网页，是负收益。

## 反模式

| 反模式 | 问题 |
|--------|------|
| 用纯文字硬讲多层嵌套结构 | 读者的工作记忆放不下，读完就忘 |
| 为了「显得专业」堆图表 | 图没解决任何理解问题，只增加阅读路径 |
| 一句话的结论做成网页 / 视频 | 打开成本远大于收益 |
| 对营销文案套 STE | 抹掉语气，与文本目的冲突 |
| 把 20/25 词上限照搬到中文 | 中文无对应标准，机械套用会切碎句子 |
| 在 `mermaid-master` / `fireworks-tech-graph` 的范围内自造图 | 重复维护源，风格与既有图不一致 |
